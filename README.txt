# DB Attendance System

This project is a simple attendance management system built using:
- PHP (mysqli)
- MySQL Database
- HTML/CSS
- XAMPP Server

## Features
- User registration & login
- Attendance tracking
- Add employees
- Record daily attendance
- View attendance reports

## How to run
1. Copy project folder into `htdocs`
2. Import the SQL file into MySQL / phpMyAdmin
3. Start Apache & MySQL in XAMPP
4. Open the project in browser:  
   `http://localhost/dbClassA`
